# Personal Free TV — USA

Paste this URL into your IPTV app's M3U playlist URL field:

https://raw.githubusercontent.com/Kingdavid3g/personal-free-tv/main/playlist.m3u

Includes 1,167 community-listed stream entries grouped by Pluto TV, Plex TV, Tubi, Samsung TV Plus, Roku Channel, Xumo, DistroTV, and Stirr. These are available public listings, not complete official service catalogs.

The URLs returned HLS manifests when checked on September 24, 2026. Actual video playback, region availability, and player compatibility can vary. This is a static playlist; automatic updates and an electronic program guide are not configured.

World at War is not included because no verified free public stream was found. Newsmax lists it as part of Newsmax+: https://www.newsmaxplus.com/

Source playlists: https://github.com/iptv-org/iptv/tree/master/streams (us_pluto.m3u, us_plex.m3u, us_tubi.m3u, us_samsung.m3u, us_roku.m3u, us_xumo.m3u, us_distro.m3u, us_stirr.m3u).

This repository hosts playlist text only, not video.
